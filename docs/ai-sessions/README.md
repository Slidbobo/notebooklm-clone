# KI-Sessions

Hier liegen die vollständigen Transkripte der Zusammenarbeit mit Claude Code,
aus der dieses Projekt entstanden ist. Sie sind Teil der Abgabe, weil das
Vorgehen genauso zur Aufgabe gehört wie das Ergebnis.

Erzeugt mit `/export docs/ai-sessions/<name>.md` aus der laufenden Session.

Vor dem Öffentlichschalten läuft `npm run scan:secrets` über die gesamte
Historie einschließlich dieser Dateien. Transkripte enthalten Werkzeugausgaben,
die nie zeilenweise gelesen wurden, und sind damit die wahrscheinlichste Stelle,
an der ein Wert steht, der dort nicht hingehört.
